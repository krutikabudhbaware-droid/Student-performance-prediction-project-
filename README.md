Student Performance Prediction 🎓

📌 About the Project

Student Performance Prediction is a Machine Learning web application that predicts students' academic performance based on input data. It uses Python and Streamlit to provide a simple and user-friendly interface.
## 🚀 Live Demo

Try EduPredict here:

https://student-performance-prediction-krutika.streamlit.app/

🎯 Objectives

- Predict student academic performance.
- Apply Machine Learning techniques to educational data.
- Help identify students who may need additional academic support.

🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

📂 Project Structure

Student_Performance_Prediction/
├── app.py
├── data/
├── model/
└── train_model.py

🚀 How to Run the Project

1. Install Python.
2. Install the required libraries:
   "pip install streamlit pandas numpy scikit-learn joblib"
3. Open the project folder in VS Code.
4. Run the application:
   "streamlit run app.py"

💡 Expected Outcome

The application accepts student-related inputs and displays a predicted academic performance result.
